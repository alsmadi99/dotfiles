# dotfiles

Personal configuration files and tooling setup.

## Contents

### `claude/`

Claude Code configuration synced across machines.

| Directory | Purpose |
|-----------|---------|
| `skills/` | Custom Claude Code skills (slash commands) |
| `projects/` | Per-project conversation history and memory |
| `sessions/` | Claude Code session data |
| `backups/` | Automatic config backups |
